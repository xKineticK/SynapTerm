# Atajos de teclado

Todos los atajos se pueden cambiar o quitar en *Ajustes → Atajos de teclado*.

| Área | Acción | Por defecto |
| --- | --- | --- |
| General | Buscar servidores (paleta de comandos) | Ctrl+Shift+K |
| General | Abrir los ajustes | Ctrl+, |
| General | Panel de sesiones (lo abre, o lo cierra si está abierto) | Alt+I |
| General | Panel de scripts de Python | Alt+Y |
| General | Panel de macros: grabar y reproducir macros | Alt+U |
| General | Panel de sesiones abiertas: cada pestaña y panel con su estado | Alt+O |
| General | Panel del Gestor de comandos | Alt+J |
| Pestañas y paneles | Nueva pestaña de terminal local | Ctrl+T |
| Pestañas y paneles | Pestaña siguiente / anterior | Ctrl+Tab / Ctrl+Shift+Tab |
| Pestañas y paneles | Ir a la pestaña 1…9 | Alt+1 … Alt+9 |
| General | Pantalla completa (activar / desactivar) | Alt+Intro |
| Terminal | Texto más grande / más pequeño / tamaño por defecto (también Ctrl+rueda del ratón) | Ctrl+= / Ctrl+- / Ctrl+0 |
| Pestañas y paneles | Clonar sesión, bloquear sesión, reconectar todas, desconectar todas | (sin atajo) |
| Pestañas y paneles | Cerrar el panel (la pestaña se cierra con su último panel) | Ctrl+W |
| Pestañas y paneles | Dividir el panel a la derecha / abajo | Ctrl+Shift+E / Ctrl+Shift+O |
| Pestañas y paneles | Ir al panel de la izquierda / derecha / arriba / abajo | Alt+Izquierda / Alt+Derecha / Alt+Arriba / Alt+Abajo |
| Terminal | Copiar la selección / pegar | Ctrl+Shift+C / Ctrl+Shift+V |
| Terminal | Buscar en la terminal | Ctrl+Shift+F |
| Terminal | Historial de comandos | Ctrl+Shift+H |
| Transferencia de ficheros | Mostrar / ocultar el explorador de ficheros | Ctrl+Shift+B |
| Edición remota | Modo IDE de la pestaña SSH (activar / desactivar) | Ctrl+Shift+D |
| Edición remota | Ir a un fichero / buscar texto en los ficheros del servidor (modo IDE, con el foco fuera de la terminal) | Ctrl+P / Ctrl+Shift+F |
| Edición remota | Abrir el servidor SSH en VS Code | (sin atajo) |
| Edición remota | Guardar el fichero del editor / cerrarlo | Ctrl+S / Ctrl+W |
| Redirección de puertos | Túneles de la pestaña SSH | Ctrl+Shift+L |
| Comandos | Comandos guardados | Ctrl+Shift+J |
| Comandos | Escribir en todos los paneles de la pestaña (activar / desactivar) | Ctrl+Shift+M |
| Comandos | Mostrar / ocultar la barra de botones; escribir en todas las sesiones abiertas | (sin atajo) |
| Automatización | Parar los scripts que se ejecutan en la pestaña activa | Ctrl+Shift+X |
| Escritorio remoto | Ctrl+Alt+Supr | Ctrl+Alt+Fin |

En un escritorio remoto, los atajos de SynapTerm siguen funcionando; el resto de teclas van al equipo remoto.

Los scripts de la biblioteca también pueden tener su propio atajo: panel *Scripts* → **⋯ → Botón y atajo…** ([Automatización](automation.md)).
