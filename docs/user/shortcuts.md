# Keyboard shortcuts

Every shortcut can be changed or removed in *Settings → Keyboard shortcuts*.

| Area | Action | Default |
| --- | --- | --- |
| General | Search servers (command palette) | Ctrl+Shift+K |
| General | Open settings | Ctrl+, |
| General | Show or hide the sidebar | Alt+I |
| Tabs & panes | New local terminal tab | Ctrl+T |
| Tabs & panes | Next / previous tab | Ctrl+Tab / Ctrl+Shift+Tab |
| Tabs & panes | Close pane (the tab closes with its last pane) | Ctrl+W |
| Tabs & panes | Split pane right / down | Ctrl+Shift+E / Ctrl+Shift+O |
| Tabs & panes | Move to the pane on the left / right / above / below | Alt+Left / Alt+Right / Alt+Up / Alt+Down |
| Terminal | Copy selection / paste | Ctrl+Shift+C / Ctrl+Shift+V |
| Terminal | Find in terminal | Ctrl+Shift+F |
| Terminal | Command history | Ctrl+Shift+H |
| File transfer | Show / hide the file browser | Ctrl+Shift+B |
| Remote editing | IDE mode of the SSH tab (on / off) | Ctrl+Shift+D |
| Remote editing | Go to file / search text in the server files (IDE mode, focus outside the terminal) | Ctrl+P / Ctrl+Shift+F |
| Remote editing | Open the SSH server in VS Code | (no default) |
| Remote editing | Save the file in the editor / close it | Ctrl+S / Ctrl+W |
| Port forwarding | Tunnels of the SSH tab | Ctrl+Shift+L |
| Commands | Saved commands | Ctrl+Shift+J |
| Commands | Type in all panes of the tab (on / off) | Ctrl+Shift+M |
| Commands | Show / hide the button bar; type in all open sessions | (no default) |
| Remote desktop | Ctrl+Alt+Del | Ctrl+Alt+End |

In a remote desktop, SynapTerm's own shortcuts keep working; every other key goes to the remote computer.

Scripts of the library can have their own shortcut too: *Scripts* panel → **⋯ → Button and shortcut…** ([Automation](automation.md)).
